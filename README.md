# 🪄 The Hogwarts Book of Spells
An interactive, voice-activated web spellbook set against an animated midnight view of Hogwarts Castle, the Black Lake, and the Forbidden Forest. 
Speak or type an incantation to trigger custom visual effects and unroll an ancient parchment scroll detailing the spell's lore.

# ✨ Features

* **🎙️ Voice-Activated Spellcasting:** Uses the Web Speech API so you can speak incantations aloud into your microphone to cast spells.
* **⌨️ Text Input Fallback:** Includes a manual incantation input bar for browsers without speech recognition support or quiet environments.
* **🎆 Custom CSS & JS Spell Effects:** Dynamic visual animations tailored to different spells—including shooting red spell beams, floating objects, burst sparks, and an owl delivery dropping a parchment scroll.
* **📜 Unrolling Parchment Modal:** Reveals the cast spell's name and description on an animated, unrolling parchment scroll sealed in wax.
* **📖 Built-in Grimoire (Spellbook):** A floating spellbook menu that lets users browse the full catalog of available incantations and their descriptions at any time.
* **🏰 Atmospheric Nightscape:** Pure CSS/SVG animated backdrop featuring twinkling stars, a glowing moon, drifting clouds, Hogwarts Castle with flickering windows, ripples on the Black Lake, and swaying trees in the Forbidden Forest.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic structure and inline SVG castle architecture
* **CSS3** — Custom properties, keyframe animations, `clip-path` silhouettes, and parchment scroll transitions
* **Vanilla JavaScript** — Web Speech API integration, DOM-driven particle/FX generation, and interactive modals
* **Google Fonts** — *Cinzel Decorative*, *Cinzel*, *EB Garamond*, and *MedievalSharp*
